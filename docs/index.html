Browse a private Google Drive folder shared by your friends, then download a selected game into the correct OnionOS ROM directory.

A small, personal-use application for a group of friends who know each other. Each participant signs in with their own Google account and needs an invitation to the shared folder.

How it works

  1. Install the Friends Library app on your Miyoo's microSD card.
  2. Authorize your own Google account using a computer, or use the optional HTTPS phone QR login when configured by your distributor.
  3. Browse friends, console folders and games using the Miyoo's physical buttons.
  4. Download a game and refresh OnionOS's ROM list. OnionOS handles normal game launching and save data.

Why Google Drive access is requested

The app uses the Google Drive drive.readonly permission to list folders, read file metadata and download files you are allowed to access. The application browses only the configured shared library. The Google permission itself covers the Drive files accessible to your account, not just that folder.

The app does not upload games, change sharing permissions, or write to your Google Drive. Listing and downloads connect to Google directly using rclone. Computer setup authorizes and renews directly with Google; optional HTTPS phone login uses a free Cloudflare service for authorization and renewal only. See the privacy policy for token handling and retention.

Source code and support

The application source is available in the Miyoo Friends Library GitHub repository. Account-specific setup information is distributed separately within the friend group. For setup support or questions about data use, contact the friend who supplied the package; the OAuth consent screen also lists the configured support email.

Only use files you are legally entitled to share and download. This website distributes no ROMs, BIOS files or account credentials.
