# OAuth information site draft

Static information pages for the user-authorized public GitHub repository
`talhaozdemir/miyoo-friends-library`. Publication is pending until confirmed by
GitHub Pages. `python scripts/sync-pages.py` copies these four assets to `/docs`;
select branch `main` and folder `/docs` in Settings > Pages. `.nojekyll` keeps
the pages static. Technical documentation in that public source folder is also
available as static files. Never select repository root for website publication.
Never deploy installation ZIP, `build/`, `.config/`, setup profile or account files.

Pages: `index.html`, `privacy.html`, `terms.html`. No build or external assets.
No cookies, JavaScript, OAuth forms, ROMs or credentials. The eventual host's
request logging is explicitly distinguished from application behavior.

Before publication, confirm the hosting address/ownership and the support contact.
Then verify domain ownership with Google as required and enter the actual URLs
in Google Auth Platform > Branding. No guarantee that URLs alone resolve all
publication or verification requirements.
